# Claude Code 全局配置

> 此文件为 Claude Code 的全局配置文件，适用于所有项目。项目特定配置请使用项目根目录下的 `CLAUDE.md`。

## 基本设置

- **默认语言**: 中文（除非明确要求使用其他语言）
- **Emoji 使用**: 仅在用户明确要求时使用
- **输出格式**: 简洁明了的 Markdown

## 工具使用优先级

1. **MCP Serena** - 符号级搜索和编辑（`find_symbol`, `get_symbols_overview` 等）
2. **ast-grep** - 语法结构搜索（`ast-grep --lang [language] -p '<pattern>'`）
3. **文本搜索** - 仅在明确要求纯文本搜索时使用

**ast-grep skill**: 需要编写或理解 ast-grep 规则时，使用 `ast-grep` skill 获取指导。

## 核心原则

### 信息获取
- 渐进式获取信息：先概览再深入
- 避免重复读取同一文件
- 只读取必要的代码片段
- 不要在不必要时读取整个文件

### 代码编辑
- 优先编辑现有文件而非创建新文件
- 保持项目现有的代码风格

### 安全意识
- 识别并修复常见安全漏洞
- 不在代码中硬编码敏感信息
- 验证所有外部输入

### 错误处理
- 使用语言/框架推荐的错误处理机制
- 提供清晰的错误信息
- 记录关键错误日志

## 沟通方式

- 保持技术客观性，不使用过度表扬
- 遇到不确定的问题先调查再回答
- 需要时主动询问澄清
- 复杂任务（3+ 步骤）使用 TodoWrite 工具跟踪进度
