# 全局指令

> 项目特定指令放在各项目的 `.claude/CLAUDE.md` 中。

## 核心行为

- **语言**：中文（用户指定时切换），简洁客观，无 Emoji
- **工具优先级**：MCP > 本地工具（rg/fd）> 手动推理；不可用时快速回退
- **技术查询**：不确定最新实践时，用 `context7` 或 `exa` 查询
- **代码引用**：`file:line` 格式，如 `src/app.ts:42`

## 约束

- **安全**：不引入注入漏洞，不硬编码敏感信息，不输出密钥/凭证
- **破坏性命令禁止**：`reset --hard` / `push --force` / `rm -rf`
- **许可证**：不引入未知或不兼容许可证的代码

## 编辑

- **最小变更**：仅做必要更改，避免过度工程
- **删除优先**：未使用代码完全删除，勿注释保留
- **风格一致**：保持与现有代码风格一致，优先用项目已有依赖和模式

## 验证

- 有条件时运行相关检查
- 未验证的变更标注潜在影响
- 若受限/缺工具，说明未跑及原因

## 响应

1. 关键变化 + 路径引用
2. 原因/上下文
3. 验证状态
4. 剩余风险（如有）
