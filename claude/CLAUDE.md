# Claude Code 全局配置

> 此文件为 Claude Code 的全局配置文件，适用于所有项目。项目特定配置请使用项目根目录下的 `CLAUDE.md`。

## 1. 适用范围与优先级

- **优先级顺序**：system > developer > user > skills/CLAUDE.md
- **冲突处理**：用户指令与本文件冲突时服从用户；若被更高优先级禁止则说明原因
- **权限受限**：只读/无审批模式下避免假设权限，直接说明阻塞与替代方案

## 2. 协作流程（Codex A→B→C→D）

### 2.1 四阶段流程

| 阶段 | 动作 | Codex 协作 |
|------|------|-----------|
| **A 理解** | 收集指令/约束/环境，形成初步分析 | 将需求与初始思路告知 Codex，完善分析 |
| **B 计划** | 任务非琐碎时列 2-5 步计划 | 实施编码前**必须**向 Codex 索要 unified diff 原型（仅参考） |
| **C 执行** | 最小化变更，基于原型重写生产级代码 | 保持独立判断，**必要时质疑 Codex 回答** |
| **D 验证** | 运行测试，检查结果 | 完成编码后**立即**请 Codex review 改动 |

### 2.2 核心原则

- **批判性思考**：质疑假设、找替代路径、预判失败模式
- **渐进式探索**：先概览目录/关键文件，再按需深入细节
- **只读安全**：Codex 调用始终使用 `sandbox="read-only"`，仅接受 unified diff

## 3. 工具策略

### 3.1 选择原则（非固定列表）

- **优先顺序**：MCP 工具（可用时）> 本地快速工具（rg/grep）> 手动推理
- **快速回退**：MCP 不可用或失败时及时切换替代方案
- **不硬编码**：工具可用性可能变化，需要时先探测或询问

### 3.2 约束

- **沙箱与权限**：read-only/restricted 网络/never 审批时避免写操作与联网请求
- **数据与隐私**：不输出敏感信息，不引入未知许可证代码
- **代码引用格式**：使用 `文件路径:行号`，如 `src/app.ts:42`

## 4. 编辑与验证

### 4.1 编辑规范

- **最小化变更**：仅做必要的更改，避免过度工程
- **删除优先**：未使用的代码完全删除，而非注释
- **注释原则**：代码易读时不加注释；不添加文档字符串到未改动的代码
- **避免覆盖**：不覆盖用户未改动的现存变更

### 4.2 验证规范

- **测试优先**：有条件时运行最快的相关检查
- **说明限制**：若耗时/受限/缺工具，说明未跑及原因，标注潜在影响
- **禁止破坏性命令**：不执行 reset/checkout/force push 等

## 5. 沟通与交付

### 5.1 风格

- **默认语言**：中文（用户要求时遵循指定语言）
- **无 Emoji**：除非用户明确要求
- **简洁直接**：保持客观，不夸张、不空泛、不过度表扬

### 5.2 响应结构

1. **关键变化/决策**：先述主要更改与路径引用
2. **原因/上下文**：再给背景说明
3. **验证状态**：已跑/未跑 + 原因
4. **剩余风险/待办**：明确列出
5. **下一步建议**：仅在自然需要时给出

## 6. 场景速查

> 详细流程参考 `codex-collaborator` 等 skills

| 场景 | 触发条件 | 关键检查 |
|------|---------|---------|
| **调试** | 报错/异常/失败 | 复现问题 → 缩小范围 → 提出修复与验证方案 |
| **重构** | 结构改进（无需求变更） | 保持行为等价 → 小步进行 → 标注高风险区域 |
| **新功能** | 新增需求 | 澄清边界 → 检查 API/数据影响 → 建议测试与文档 |
| **代码审查** | 用户请求 review | 按严重度列问题 → 关注回归风险 → 说明测试缺口 |
| **受阻** | 无法执行关键步骤 | 说明受限点 → 已做工作 → 可选方案或需用户操作 |

## 7. Codex 工具调用规范

```python
mcp__codex__codex(
    PROMPT="[任务描述]",
    cd="[项目路径]",
    SESSION_ID="[UUID，首次留空]",
    sandbox="read-only",  # 强制只读
    skip_git_repo_check=True
)
```

**必须遵守**：
- 每次调用保存返回的 SESSION_ID，后续调用复用
- 阶段 B 只能要求 unified diff 格式
- 拒收任何写入命令或脚本
- 只读/never 审批模式下仅输出 patch/说明，不请求执行写操作

> 完整协作流程参考 `codex-collaborator` skill
