# 开发指南

优先级：正确性 > 可读性 > 性能。行为不变优先于重构；代码风格服从项目 linter/formatter。

## 决策与沟通

- 需求有多种解读且导致不同实现、或操作不可逆时，列出选项让用户选；有常规默认值的小决定直接选，并在回复中写明所选。
- 执行中发现前提不成立或理解有误：停下，说明卡点、可选方案和影响，等确认再继续。
- 有更简单的方案就指出；对过度设计或有风险的方案直接推回。
- 同一问题试 3 次仍未解决：停止试错，汇报现状、证据和假设，等待指示。
- 库/框架/SDK/API/CLI 用法不确定时，先查 context7 或 exa 的最新文档；内部数据结构/字段名不确定时，先读 schema 或代码定义。

## 最小 diff

- 每一行 diff 都能追溯到用户请求。未要求的功能、抽象、配置、兼容层，以及邻近代码的重构/格式化/"改进"，都留给用户决定。
- 改前先搜现有实现，复用既有函数、工具、模式。
- 单次使用的逻辑保持内联；只处理已知可达的失败路径。
- 新增依赖前先告知用户并说明理由；标准库或现有依赖够用就用它们。
- 清理范围限于本次改动产生的孤儿 import/变量/函数；改动前已存在的死代码或问题，在回复中告知用户。

## 验证

- 先把任务转成可验证目标，测试先 red 后 green：加校验 → 失败测试；修 bug → 复现测试；重构（尤其 legacy）→ 改前补测试，前后都过。
- 关键业务逻辑须有测试覆盖；项目无测试框架时逐步引入，先覆盖本次改动的关键路径；描述不出用例时先澄清需求。
- 多步任务先列 checklist，每项写明验证点；验证通过才打勾（"做完了"不算通过）。收尾列出未完成或跳过的项及原因。
  - 超过 5 步或可能跨会话：写入项目下 `.claude/checklists/<任务简称>.md`（已全局 gitignore），每完成一项即更新；新会话或上下文压缩后先读它恢复进度；全部完成后删除。
- 汇报完成时附证据：执行的命令及其输出（测试结果等）。
- 非代码任务（报告、配置、数据文档）：数字取自权威数据源的实时结果（数据库/API/CLI）；产出后与相关文件交叉核对一致性。

## 正确性底线

- `catch` 只做三件事之一：记录、重抛、转为显式返回值。
- 轮询、重试、爬取用显式的最大次数变量封顶。
- 资源关闭覆盖所有退出路径，含异常路径。
- 副作用体现在函数签名上；可变状态经参数/返回值传递。
- 前提条件写成断言或显式校验。
- 改动触及**敏感域**（金额、权限、用户数据、并发、加密）时，主动提示用户审阅。

## 注释

- 注释写 why（意图、权衡、为何不用另一种写法）；what 交给好命名和小函数。
- 关键业务逻辑、公共 API、兼容性处理及敏感域代码，用英文注释写清 why、业务约束、边界条件和陷阱；公共 API 另写参数、返回、异常、前置/后置条件。
- 改代码时同步更新或删除相关注释；旧代码交给 git，变更记录交给 commit message。

## 工具与环境

- Python 一律经 uv：单文件脚本 `uv run <script>.py`，依赖写在文件头 PEP 723 内联元数据（`# /// script` … `dependencies = [...]` … `# ///`）；多文件项目用 `uv venv` / `uv add` / `uv sync`。
- 文本搜索用 `rg`，文件名/路径用 `fd`。二者默认跳过隐藏文件与 gitignore 内容：点文件/点目录（`.env`、`.github/`）加 `rg --hidden`/`fd -H`，被 ignore 的内容（`node_modules/`、`dist/`、本地数据目录）加 `rg -uu`/`fd -u`。"没搜到"先排除这一层再下结论。
- 列目录用 `fd`：`ls` 被 alias 成带 `--icons` 的 eza，`ls <dir>` 会报 `invalid value for '--icons'`。
- 限时用 Bash 工具的 `timeout` 参数（毫秒）：macOS 没有 `timeout` 命令。
- 符号导航（定义/引用/实现/调用链）在 Go/gopls、Python/pyright、Rust/rust-analyzer 中先用 `LSP` 工具——按语义解析，不受同名字符串和注释干扰；报错或无结果时回退 `rg`。文本、配置、注释用 `rg`。
  - rust-analyzer 只加载启动目录本身或其下一层的 `Cargo.toml`；更深的 crate 或无 `Cargo.toml` 的单文件只有 `documentSymbol` 可用，语义查询返回空＝项目未加载（不代表无引用），直接用 `rg`。
