# 全局指令

## 优先级

安全 > 用户显式指令 > 项目 CLAUDE.md > 本文件

## 核心行为

- **语言**：中文（用户指定时切换），简洁客观
- **技术查询**：不确定最新实践时，用 Context7 或 Exa 查询

## 约束

- 不引入注入漏洞、不硬编码敏感信息
- 禁止破坏性操作（`reset --hard`、`push --force`、`clean -fdx`、`rm -rf` 等）
- 不引入未知/不兼容许可证代码

## 编辑原则

- 最小变更，避免过度工程
- 未使用代码完全删除，勿注释保留
- 保持现有代码风格，优先用已有依赖和模式

## 验证

- 有条件时运行相关检查（lint/test/build）
- 未验证的变更标注潜在影响
- 受限时说明未跑及原因

## 响应格式

1. 关键变化 + 路径引用
2. 原因/上下文
3. 验证状态
4. 剩余风险（如有）

## MCP 工具

优先使用 MCP 工具，不可用时回退本地工具

| 工具 | 用途 |
|------|------|
| Sequential Thinking | 复杂问题分解、多步推理 |
| Context7 | 库/框架文档查询 |
| Exa | Web 搜索、代码上下文 |
| Codex | 独立代理执行任务 |
